# Spec Delta

## MODIFIED Requirements

### Requirement: Навигация с экрана
Под таблицей SHALL быть кнопка «Назад» (возврат на «Отчёты»). Кнопки
«Иконки» нет: общие и чужие иконки — во вкладке «Отчёты» → «Иконки».

#### Scenario: Назад
- **WHEN** администратор нажимает «Назад»
- **THEN** «Отчёты» открываются заново на вкладке «Обзор»

#### Scenario: Нет кнопки «Иконки»
- **WHEN** администратор открывает «Список пользователей»
- **THEN** под таблицей только кнопка «Назад»
