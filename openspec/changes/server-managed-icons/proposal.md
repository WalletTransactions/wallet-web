# Proposal

## Why

Иконки на телефон теперь приходят только с сервера: телефон свои иконки
больше не отправляет (парный change `android-wallet: server-managed-icons`),
а общий набор ведёт администратор. Сейчас админский экран «Иконки» только
показывает набор — пополнить его неоткуда. wallet-api добавляет ручки записи
(`wallet-api: server-managed-icons`); вебу нужен интерфейс к ним.

## What Changes

- На админском экране «Иконки» в разделе «Общие» — форма «Добавить иконку»:
  файл картинки, название, тип («Категория» / «Флаг»). Картинка в браузере
  приводится к квадрату 256×256 (WEBP, если браузер умеет, иначе PNG),
  загружается в `POST /sync/blobs`, затем создаётся иконка
  `POST /api/admin/icons`.
- У каждой общей иконки — «Переименовать» и «Удалить» (`PATCH`/`DELETE
  /api/admin/icons/{uuid}`), с понятными сообщениями о дубле имени и об
  иконке, которая используется.
- Пояснение на экране говорит, что общий набор приезжает на телефоны при
  синхронизации.
- Иконки пользователя и экран «Иконки» в «Отчётах» остаются только для
  просмотра.

### Modified Capabilities

  удаление общих иконок; меняется текст пояснения.

## Impact

- `site/app.js` (`renderAdminIconsScreen`, новая обработка картинки через
  `<canvas>`), `site/style.css` (форма и кнопки в ячейке сетки), `README.md`
  (раздел админских иконок).
- Зависит от wallet-api: `POST /sync/blobs` (есть) и `/api/admin/icons*`
  (новые). wallet-report, google-auth, wallet-gateway — без правок.
