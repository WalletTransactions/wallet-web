# Spec Delta

## MODIFIED Requirements

### Requirement: Состав экрана «Настройки»
Экран SHALL состоять из кнопки «← Назад» (возврат на «Отчёты» с вкладки «Обзор») и
секций «Валюта эквивалента», «Формат даты», «Пароль», «Устройства» и «Опасная зона» в этом
порядке. Секция «Пароль» SHALL показываться только если `GET /auth/methods`
вернул `password`.

#### Scenario: Открытие настроек
- **WHEN** пользователь нажимает «Настройки» в сайдбаре, а вход по паролю включён
- **THEN** показываются пять секций, а список устройств сначала показывает «Загрузка…»

#### Scenario: Вход по паролю выключен
- **WHEN** `GET /auth/methods` вернул `{"methods":["google"],"registration":false}`
- **THEN** секции «Пароль» нет, остальные четыре на месте

#### Scenario: Возврат
- **WHEN** пользователь нажимает «← Назад»
- **THEN** «Отчёты» открываются заново на вкладке «Обзор»

## ADDED Requirements

### Requirement: Пароль для входа
Секция «Пароль» SHALL содержать поля «Новый пароль» и «Повторите пароль» и кнопку
«Сохранить пароль»; если у пользователя уже есть пароль, дополнительно — поле
«Текущий пароль». SPA SHALL отправлять `POST /auth/password` с телом
`{"password", "current_password"}` и при `204` показывать «Пароль сохранён.
Остальные сессии закрыты.». Проверки длины и совпадения — как в «Регистрации»
(`web-session`). Ответ `401` — «Неверный текущий пароль.». Окончательный `401`
сессии — экран входа.

#### Scenario: Пользователь Google задаёт пароль
- **WHEN** пользователь, вошедший через Google, вводит и повторяет новый пароль и нажимает «Сохранить пароль»
- **THEN** выполняется `POST /auth/password` без `current_password`, показывается «Пароль сохранён. Остальные сессии закрыты.»

#### Scenario: Неверный текущий пароль
- **WHEN** сервер отвечает `401 {"error":"неверный текущий пароль"}`
- **THEN** показывается «Неверный текущий пароль.», пароль не меняется
