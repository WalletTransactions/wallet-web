# Proposal

## Why

google-auth вводит персональные MCP-токены
(`google-auth/openspec/changes/add-mcp-personal-tokens`): по такому токену
LM Studio, а позже любой MCP-клиент читает кошелёк через `wallet-mcp`.
Выпустить токен может только сам пользователь, будучи вошедшим. Показать
токен можно один раз, а потом нужно видеть, где он используется, и уметь его
отозвать. Естественное место для этого — секция «Активные сессии» на экране
«Настройки»: MCP-токены там и так появятся как сессии с `platform: "mcp"`.

## What Changes

- На экране «Настройки», в секции устройств, появляется кнопка «Подключить
  MCP-клиент». Она открывает форму с именем токена (например, «LM Studio дома»)
  и вызывает `POST /auth/mcp-tokens` google-auth.
- Выпущенный токен показывается **один раз**: поле только для чтения, кнопка
  «Скопировать», готовый фрагмент конфига MCP-клиента (адрес
  `http://<хост>:8090/api/mcp/` и заголовок `Authorization: Bearer …`) и
  предупреждение, что токен больше не будет показан. После закрытия окна
  токен из страницы удаляется.
- В списке устройств MCP-сессии отмечаются отдельно (`platform: "mcp"`, имя
  токена). Для всех сессий, где google-auth это отдаёт, показываются «последнее
  использование» и «действует до». Отзыв MCP-токена — та же кнопка «Отозвать».
- В подтверждении «Закрыть все остальные сессии» явно сказано, что MCP-клиенты
  тоже отключатся.

### Modified Capabilities
- `user-settings`: выпуск MCP-токена с одноразовым показом; отображение
  MCP-сессий, последнего использования и срока в «Списке устройств»; текст
  подтверждения «Закрыть все остальные сессии».

## Impact

- **wallet-web:** `site/app.js` (секция `#settings-devices`, новая форма и окно
  показа токена), `style.css` при необходимости, раздел «Настройки» в
  `README.md`. Работает и на ширине телефона.
- **google-auth:** зависимость — `POST /auth/mcp-tokens` и новые поля в
  `GET /auth/devices` из `add-mcp-personal-tokens`. Веб выкатывается после
  google-auth.
- **wallet-gateway:** без правок, `/auth/*` уже проксируется.
- **Безопасность:** токен существует только в памяти страницы до закрытия
  окна. Его не пишут в `localStorage`, в URL и в журнал браузера. Адрес в
  готовом конфиге берётся из `location.origin`, поэтому в test-контуре
  подставится адрес test.
