# Spec Delta

## Purpose

Как сервис отдаёт SPA: образ nginx со статикой из `site/`, SPA-фолбэк на
`index.html`, правила кэширования и версия в адресах своих скриптов и стилей,
сжатие, документация `/docs` и `/openapi.yaml`. Собственного HTTP API и
конфигурации окружения у сервиса нет.

## ADDED Requirements

### Requirement: Только статика
Сервис SHALL отдавать только файлы из `site/` через nginx без проксирования и
серверного кода. Вся динамика — запросы браузера через wallet-gateway, для
которого этот сервис — маршрут по умолчанию.

#### Scenario: Запрос API напрямую к сервису
- **WHEN** кто-то запрашивает `/api/reports/balance` прямо у контейнера wallet-web
- **THEN** nginx отдаёт `index.html` (фолбэк), а не данные

### Requirement: SPA-фолбэк
Для пути без соответствующего файла nginx SHALL отдавать `index.html` со
статусом `200`, чтобы клиентские адреса (`/join/<token>`, hash «Отчётов»)
открывались прямым заходом.

#### Scenario: Прямой заход по ссылке-приглашению
- **WHEN** браузер открывает `/join/abc`
- **THEN** приходит `index.html`, и SPA сама разбирает путь

### Requirement: Состав страницы
`index.html` SHALL быть оболочкой с заголовком «Кошельки», фавиконкой
`/favicon.svg`, стилями `/style.css`, вендоренной библиотекой
`/vendor/qrcode-generator/qrcode.js` и `/app.js`; до запуска скрипта видна
надпись «Загрузка…».

#### Scenario: Скрипт ещё грузится
- **WHEN** страница открыта, а `app.js` не выполнился
- **THEN** пользователь видит карточку с «Загрузка…»

### Requirement: Свежие версии после выката
Ответы nginx SHALL нести `Cache-Control: no-cache` (переспрос по ETag), а при
сборке образа адреса `/app.js` и `/style.css` в `index.html` SHALL получать
`?v=<первые 10 символов md5 файла>`. Сборка образа MUST падать, если подстановка
не произошла.

#### Scenario: Выкатили новый app.js
- **WHEN** после выката телефон открывает страницу, ранее закэшированную
- **THEN** `index.html` переспрашивается, содержит новый `app.js?v=<хэш>`, и браузер загружает новый скрипт

### Requirement: Сжатие
nginx SHALL сжимать gzip ответы типов CSS, JavaScript, JSON и SVG от 256 байт.

#### Scenario: Загрузка app.js
- **WHEN** браузер с `Accept-Encoding: gzip` запрашивает `/app.js`
- **THEN** ответ приходит сжатым

### Requirement: Никаких внешних запросов
Страница MUST NOT загружать ресурсы с внешних адресов: библиотеки (QR-код,
Swagger UI) лежат в `site/vendor/`, шрифты — системные.

#### Scenario: Стенд без интернета
- **WHEN** стенд в LAN без доступа наружу
- **THEN** приложение, QR-код подключения бота и `/docs` работают полностью

### Requirement: Документация сервиса
`/openapi.yaml` SHALL отдавать спецификацию, описывающую только SPA-фолбэк и два
адреса документации, а `/docs` — Swagger UI поверх неё. Контракты `/auth/*`,
`/api/*`, `/admin/*` описаны в репозиториях соответствующих сервисов.

#### Scenario: Открыта документация
- **WHEN** пользователь открывает `/docs` через гейтвей
- **THEN** показывается Swagger UI со спецификацией wallet-web

### Requirement: Без конфигурации окружения
Сервис MUST NOT требовать `.env` или переменных окружения: все адреса в `app.js`
относительные. Контейнер слушает порт `80`.

#### Scenario: Запуск контейнера
- **WHEN** образ запущен без переменных окружения
- **THEN** nginx стартует, и `nginx -t` проходит

### Requirement: Проверка в CI
CI SHALL на каждый push в `main` и pull request (кроме изменений только `*.md`)
собирать образ и проверять конфиг командой `nginx -t`; образ никуда не
публикуется.

#### Scenario: Сломанный nginx.conf
- **WHEN** в pull request конфиг nginx содержит синтаксическую ошибку
- **THEN** шаг «Check nginx config» падает
