# Spec Delta

## Purpose

Просмотр иконок: экран «Иконки» в «Отчётах» показывает иконки, доступные
леджеру пользователя (свои и общий набор), а администратор на отдельном
экране видит общий набор и собственные иконки любого пользователя. Только
чтение; картинки берутся из `GET /sync/blobs/{sha256}` (wallet-api).

## ADDED Requirements

### Requirement: Экран «Иконки» в «Отчётах»
Экран SHALL загружаться один раз при открытии «Отчётов» через
`GET /api/reports/icons` (общий кэш отчётов, с `as_user_id` в режиме
«Посмотреть как клиент») и показывать разделы «Мои (N)» и «Общие (N)». Фильтр
периода на этой вкладке скрыт. Ошибка — «Не удалось загрузить иконки:
<причина>».

#### Scenario: Просмотр как клиент
- **WHEN** администратор смотрит «Отчёты» как клиент и открывает «Иконки»
- **THEN** запрос уходит с `as_user_id` клиента, в «Мои» — иконки клиента

### Requirement: Сетка иконок
Каждая иконка SHALL показываться крупным кругом с картинкой из
`/sync/blobs/{sha256}` фоном (без «сломанной картинки», если blob не
найден) и подписью-названием. Пустой набор — «Иконок нет.».

#### Scenario: Нет своих иконок
- **WHEN** пользователь не добавлял своих иконок
- **THEN** под «Мои (0)» написано «Иконок нет.»

### Requirement: Админский экран иконок
Кнопка «Иконки» на экране пользователей (только администратор) SHALL
открывать экран «Иконки» с разделом «Общие» (`GET /api/reports/admin/icons`)
и разделом «Иконки пользователя» с выбором пользователя из `GET /admin/users`
(«— выбрать пользователя —» по умолчанию). Выбор пользователя SHALL загружать
`GET /api/reports/admin/icons?user_id=<id>` и показывать его иконки; сброс
выбора очищает раздел. «Назад» возвращает к экрану пользователей.

#### Scenario: Иконки пользователя
- **WHEN** администратор выбирает пользователя в списке
- **THEN** под списком показаны собственные иконки этого пользователя

#### Scenario: Ошибка загрузки иконок пользователя
- **WHEN** запрос иконок пользователя завершился ошибкой
- **THEN** под списком показано «Не удалось загрузить: <причина>»

### Requirement: Ошибки админского экрана
Если не удалось загрузить общий набор или список пользователей, SHALL
показываться экран ошибки «Не удалось загрузить иконки: <причина>»; при 401
— экран входа.

#### Scenario: Сессия истекла
- **WHEN** `GET /api/reports/admin/icons` отвечает 401
- **THEN** показывается экран входа
