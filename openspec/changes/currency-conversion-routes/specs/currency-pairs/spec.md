# Spec Delta

## ADDED Requirements

### Requirement: Маршруты пересчёта на экране «Курсы валют»
Экран SHALL иметь третью вкладку «Маршруты пересчёта» (поведение — спека
`currency-routes`). Удаление пары SHALL обновлять и список маршрутов:
wallet-api вместе с парой мягко удаляет использующие её маршруты, поэтому после
`DELETE /api/currency-pairs/{uuid}` обе выборки перезапрашиваются.

#### Scenario: Пара в маршруте
- **WHEN** пользователь удаляет пару `EURRUB`, входящую в маршрут «BTC → EUR → RUB»
- **THEN** после обновления маршрута «BTC → EUR → RUB» в списке нет
