# Proposal

## Why

Эквивалент в отчётах и таблице кошельков показывает «нет курса» для валют без
прямой пары к валюте эквивалента (например, BTC → RUB при наличии BTC/EUR и
EUR/RUB). В кабинете нет способа задать маршрут пересчёта через
промежуточную валюту; в android-wallet и wallet-api такой маршрут вводится
(см. одноимённые change). Без управления маршрутами в вебе пользователь
вынужден настраивать их только на телефоне.

## What Changes

- На экране «Курсы валют» появляется блок «Маршруты пересчёта»: список
  маршрутов леджера в виде `BTC → EUR → RUB`, добавление (выбор пути из
  3–4 валют справочника леджера; пары и направления шагов подбирает сервер)
  и удаление своих маршрутов.
- Экран работает поверх нового REST wallet-api `/api/currency-routes*`
  (список, создание, удаление); загрузка — вместе со списком пар, не зависит
  от периода и валюты эквивалента.
- Проверки на форме до запроса: три валюты выбраны и различны, такой маршрут
  уже есть — сообщение об ошибке; ошибки сервера показываются так же, как у
  пар.
- Эквивалент в KPI, таблице кошельков и «Состоянии по валюте» (`wallet-balances`)
  считается сервером (через wallet-report и вьюху курса wallet-api), поэтому
  отдельной логики пересчёта в вебе не появляется; меняется только то, что
  валюта без прямой пары начинает получать эквивалент и пометку `≈`
  вместо «нет курса» и `~`.

## Capabilities

### New Capabilities
- `currency-routes`: управление маршрутами пересчёта в кабинете — список,
  добавление, удаление, проверки формы.

### Modified Capabilities
- `currency-pairs`: экран «Курсы валют» содержит блок маршрутов; загрузка
  экрана включает список маршрутов.

## Impact

- Код: `site/app.js` (экран «Курсы валют», загрузка и рендер блока маршрутов),
  разметка/стили вкладки.
- Зависимости: новый REST `/api/currency-routes*` в wallet-api; без него
  блок недоступен. Порядок выката: wallet-api → wallet-web.
- Тесты: сценарии экрана «Курсы валют» (добавление, дубликат, удаление,
  пустое состояние, ошибка загрузки).
