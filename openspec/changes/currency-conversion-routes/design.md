# Design

## Context

Экран «Курсы валют» (`site/app.js`, `renderCurList`/`wireCurEvents`) — один
корневой `#cur-root`, полная перерисовка innerHTML, один делегирующий слушатель
кликов; вкладки «Валютные пары» / «Справочник валют» переключает `curTab`.
wallet-api (одноимённый change, PR #45) даёт `/api/currency-routes*`: клиент
присылает путь из валют, сервер подбирает пары и направления шагов.

## Goals / Non-Goals

**Goals:** список, создание по пути из валют и удаление маршрутов с веба.
**Non-Goals:** своя логика пересчёта (эквиваленты считает сервер), редактирование
шагов вручную (выбор пар и направления — на стороне сервера), маршруты длиннее
4 валют.

## Decisions

### 1. Вкладка, а не блок под списком пар
Третья вкладка `curTab = 'routes'` рядом с существующими: у пар таблица с
поиском и формой, добавлять второй блок на тот же экран — длинная прокрутка и
конфликт состояний форм. Вкладка повторяет приём «справочника валют».
В proposal это называлось «блок» — по сути тот же раздел экрана.

### 2. Загрузка вместе с парами, ошибка изолирована
`refreshCurrencyPairs()` после пар запрашивает маршруты (`curRoutes`,
`curRoutesError`). Падение `/api/currency-routes` не ломает экран: ошибка
показывается только на вкладке маршрутов. Удаление пары и создание/удаление
маршрута перезапрашивают обе выборки (пара каскадно снимает маршруты на
сервере).

### 3. Форма пути из валют
`curRoutePath` — массив uuid длиной 3–4 (`['', '', '']`); пикеры — та же разметка
`.currency-picker`, что у «Добавить пару», но индексированные
(`data-route-toggle`/`data-route-pick`). «Ещё промежуточная» вставляет валюту
перед последней, «Убрать» удаляет её. Проверки до запроса — по
`curRoutes` (дубль по неупорядоченной паре «Из»/«В»); серверные `400/409`
показываются в форме строкой, без `alert` (как в форме валюты).

### 4. Нужна ли правка в других сервисах
Нет: wallet-api (`/api/currency-routes*`, PR #45) уже есть, wallet-gateway
пропускает `/api/*` как есть, wallet-report не затронут. Порядок выката:
wallet-api → wallet-web.

## Risks / Trade-offs

- [Автотестов у веба нет] → ручная проверка в браузере на test (десктоп и ширина
  телефона), сценарии спеки.
- [Список маршрутов не покажет недостроенные цепочки с телефона] → так задумано
  сервером; пользователь может пересоздать маршрут — оборванный замещается.
