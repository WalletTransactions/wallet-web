# Proposal

## Why

В вебе нужен помощник «как это работает»: обычный пользователь спрашивает про сайт, а
администратор — про всю систему (сервисы, контур, клиенты) и получает ответ по
OpenSpec-спекам. Ответы даёт необязательный сервис `wallet-docs` (change
`wallet-docs-assistant` в wallet-infra); какие спеки доступны, решает сервер по `role` и
`platform` из токена. Вебу остаётся показать вход и ответ, и только когда сервис есть.

## What Changes

- Новый пункт «Справка» в боковом меню «Отчётов» (по образцу группы «ИИ»). Он скрыт, пока
  `GET /api/docs/status` не ответил `200`; при любом другом ответе или ошибке сети его нет.
- Экран «Справка»: поле «Ваш вопрос…», кнопка «Спросить», ответ текстом, под ним «Источники»
  (у администратора — «репозиторий · раздел», у остальных — только раздел).
- В режиме «Посмотреть как клиент» пункта нет (запрос шёл бы с правами администратора).
- Запросы идут через wallet-gateway: `GET /api/docs/status`, `POST /api/docs/ask`
  (контракт — `openapi.yaml` wallet-docs). Клиент не сообщает, кто он: сервер берёт `role`
  и `platform` из токена.
- Никаких внешних запросов и библиотек: чистый JS в `site/app.js`, стили в `style.css`.

## Capabilities

### New Capabilities
- `docs-assistant`: пункт «Справка», скрытие при недоступном сервисе, вопрос и ответ с
  источниками, различия подписей источников для администратора и остальных, ошибки.

### Modified Capabilities

## Impact

- **wallet-web**: `site/app.js` (статус, вид «Справка», запрос), `site/style.css`, `site/index.html` (группа меню), README (раздел экрана).
- **Другие сервисы**: google-auth (`docs-audience`), wallet-gateway (`docs-route`), wallet-docs.
- **wallet-web-eqdefault** не затрагивается: при необходимости — отдельный change.
