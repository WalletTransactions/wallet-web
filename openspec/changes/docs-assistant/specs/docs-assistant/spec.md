# Spec Delta

## Purpose

Справка по системе в вебе: вопрос своими словами и ответ с указанием разделов описания. Для администратора область шире, чем для остальных, но выбирает её сервер; раздел необязателен и скрыт, если сервис не подключён.

## ADDED Requirements

### Requirement: Пункт «Справка» только при доступном сервисе
Веб SHALL показывать в боковом меню «Отчётов» пункт «Справка» только если
`GET /api/docs/status` ответил `200`. При другом ответе (`404`, `401`, `502`) или ошибке
сети пункта SHALL NOT быть, остальные пункты и экраны SHALL работать как раньше. Статус
запрашивается один раз при открытии «Отчётов» и не задерживает остальные запросы. В
режиме «Посмотреть как клиент» пункта нет.

#### Scenario: Сервис подключён
- **WHEN** пользователь вошёл и открыл «Отчёты», а `GET /api/docs/status` отвечает `200`
- **THEN** в меню виден пункт «Справка»

#### Scenario: Сервис не подключён
- **WHEN** `GET /api/docs/status` отвечает `404`
- **THEN** пункта нет, в консоли браузера нет необработанных ошибок, остальное меню на месте

#### Scenario: Режим просмотра клиента
- **WHEN** администратор включил «Посмотреть как клиент»
- **THEN** пункта «Справка» нет

### Requirement: Вопрос и ответ
Экран «Справка» SHALL содержать поле «Ваш вопрос…» (до 1000 символов) и кнопку «Спросить».
По нажатию (или Ctrl+Enter в поле) веб SHALL отправить `POST /api/docs/ask` с вопросом и
показать ответ текстом и под ним блок «Источники». Пока идёт запрос, кнопка недоступна, а
в области ответа написано «Ищу ответ…». Веб SHALL NOT хранить вопросы и ответы после ухода
с экрана или перезагрузки страницы.

#### Scenario: Успешный ответ
- **WHEN** пользователь вводит «Как работает вход?» и нажимает «Спросить», а сервис отвечает `200`
- **THEN** под полем показан текст ответа и блок «Источники»

#### Scenario: Пустой вопрос
- **WHEN** поле пусто или состоит из пробелов
- **THEN** кнопка «Спросить» недоступна, запрос не уходит

#### Scenario: Перезагрузка
- **WHEN** пользователь обновляет страницу (F5) на экране «Справка»
- **THEN** экран открывается с пустым полем; пункт остаётся выбранным, если статус `200`

### Requirement: Подписи источников
Блок «Источники» SHALL показывать для администратора строки «<репозиторий> · <раздел>», а
для остальных пользователей — только «<раздел>». Роль веб берёт из ответа `GET /auth/me`;
какие источники доступны, определяет сервер.

#### Scenario: Администратор
- **WHEN** администратор получает ответ с источником `{repo: "wallet-web", capability: "web-session"}`
- **THEN** в «Источниках» строка «wallet-web · web-session»

#### Scenario: Обычный пользователь
- **WHEN** пользователь с ролью `user` получает ответ с тем же источником
- **THEN** в «Источниках» строка «web-session», без имени репозитория

### Requirement: Ошибки не ломают экран
При ошибке веб SHALL оставить введённый вопрос в поле и показать под ним сообщение:
«Нет связи. Попробуйте позже.» при сетевой ошибке; «Сервис ответов недоступен» при `404`,
`502`, `503`; «Сессия истекла, войдите заново» при `401`; текст ошибки сервиса при `400`.
Повторное нажатие «Спросить» SHALL отправлять запрос заново.

#### Scenario: Сервис остановили
- **WHEN** сервис отвечает `502` на `POST /api/docs/ask`
- **THEN** под полем «Сервис ответов недоступен», вопрос остался, кнопка снова доступна

### Requirement: Телефон
Экран «Справка» SHALL работать на ширине телефона: пункт доступен из мобильного меню так
же, как пункт «ИИ», поле и ответ занимают всю ширину без горизонтальной прокрутки.

#### Scenario: Ширина 390px
- **WHEN** окно уже ~700px и открыт экран «Справка» с длинным ответом
- **THEN** страница не прокручивается по горизонтали, кнопка «Спросить» видна без прокрутки
