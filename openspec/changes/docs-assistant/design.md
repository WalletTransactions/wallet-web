# Design

## Context

`site/app.js` — один файл в IIFE, ES5-стиль, без сборки. Функции ИИ скрыты до ответа
`GET /api/ai/status`: `refreshAiStatus()` вызывается при открытии «Отчётов», группа меню
`nav-group-ai` скрыта по умолчанию, в режиме «Посмотреть как клиент» запрос не делается.
Аутентификация — httpOnly-cookie `session`, JS токен не видит. См. proposal.md.

## Goals / Non-Goals

**Goals:**
- Пункт «Справка» по образцу «ИИ»: появляется только при `200` на статусе.
- Один вопрос — один ответ с источниками; подпись источников различается по роли.

**Non-Goals:**
- История диалога, потоковый вывод, markdown-рендеринг ответа (выводится как текст).
- Выбор области документации на клиенте: её определяет сервер по токену.
- wallet-web-eqdefault.

## Decisions

**D1. Копируем приём `refreshAiStatus`, а не обобщаем.** Отдельные `docsStatus`,
`refreshDocsStatus()` и группа меню `nav-group-docs`. Вызов — рядом с `refreshAiStatus()`
при открытии «Отчётов». Общая абстракция «модуль по статусу» для двух мест избыточна.

**D2. Статус не повторяется при ошибках ответа.** Любой не-200 или сеть → пункт скрыт до
следующего открытия «Отчётов». Сессией займутся остальные запросы, как у ИИ.

**D3. Ответ — текст, не HTML.** Пишется в `textContent`, строки источников собираются
через `escapeHtml`, чтобы текст из индекса и вопрос не исполнились как разметка.

**D4. Роль для подписей — из `currentUser.role`** (уже загружается из `/auth/me`). Это
подсказка отображения; доступ к данным определяет сервер по токену.

**D5. Режим «Посмотреть как клиент» прячет пункт.** Токен остаётся администраторским,
ответ показал бы всю систему под видом клиентского экрана — как у ИИ, где запись ушла бы
в кошелёк администратора.

**D6. Размещение на телефоне как у «ИИ».** Пункт живёт в той же навигации; отдельной
раскладки не вводим, проверяем на ширине до ~700px.

**Правки вне wallet-web:** google-auth (`docs-audience`), wallet-gateway (`docs-route`),
wallet-docs. Парных правок в android-wallet нет, кроме собственного change.

## Risks / Trade-offs

- [Длинные ответы ломают раскладку] → `overflow-wrap: anywhere` и ограничение высоты с
  прокруткой внутри области ответа; проверка на 390px.
- [Токен без `wallet-docs` до обновления сессии] → `401` на статусе, пункт скрыт; после
  refresh (до 15 минут) появится при следующем открытии «Отчётов».
- [Ответ приходит на языке документации] → допущение: интерфейс сайта русский, документация
  русская.
