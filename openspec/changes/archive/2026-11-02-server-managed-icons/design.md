# Design

## Context

- Админский экран — `renderAdminIcons` → `renderAdminIconsScreen(commonIcons,
  users)` в `site/app.js`; сетка — `iconGridHtml`, картинка — фоном из
  `/sync/blobs/{sha256}` (`categoryIconHtml`).
- Запросы — `apiFetch`/`apiJson` с `credentials: 'include'`, при 401 сами
  показывают экран входа. Подтверждения в SPA делаются `window.confirm`.
- Сессия браузера — токен без `device_id`; `POST /sync/blobs` такой токен уже
  принимает (`wallet-api`, `icon-blobs`), scope `wallet:write` у сессии есть
  (тот же, что нужен валютным парам).
- Телефон хранит иконки как WEBP 256×256 и декодирует их `BitmapFactory`
  (понимает и WEBP, и PNG).

## Goals / Non-Goals

**Goals:** добавить/переименовать/удалить общую иконку без выхода из SPA,
без сборки и без новых библиотек.

**Non-Goals:** смена типа и картинки существующей иконки (тип задаётся при
создании; картинку сервер не меняет), управление иконками пользователей,
drag-and-drop и пакетная загрузка.

## Decisions

1. **Обработка картинки в браузере через `<canvas>`**: objectURL файла
   (`URL.createObjectURL`, не `FileReader`/dataURL — фото в 10+ МБ не
   раздувается в base64-строку) → `Image` → квадратная обрезка по центру в canvas 256×256 →
   `canvas.toBlob(cb, 'image/webp', 0.9)`; если `blob.type !== 'image/webp'`
   (Safari отдаёт PNG) — используем что вернулось (PNG). Альтернатива —
   слать оригинал и сжимать на сервере: wallet-api пришлось бы тянуть
   библиотеку изображений ради одной админской ручки. Canvas доступен везде,
   и размер на выходе (~10–40 КиБ) далеко от лимита 1 МиБ.
2. **Два запроса последовательно** (`/sync/blobs`, затем `/api/admin/icons`)
   — контракт wallet-api. Если второй упал, загруженный blob остаётся
   (повторное «Добавить» его не дублирует — дедупликация по хешу).
3. **Перерисовка только раздела «Общие»**, а не всего экрана: выбранный
   пользователь в нижнем разделе не сбрасывается. Раздел «Общие»
   выносится в свой контейнер `#admin-icons-common` и функцию
   `refreshAdminCommonIcons()`.
4. **`iconGridHtml(icons, opts)`** получает необязательный флаг
   `editable`: кнопки рисуются только для общего набора на админском экране,
   остальные вызовы не меняются. Обработчики — делегированием на контейнере
   по `data-uuid`.
5. Сообщения об ошибках — в элементе рядом с формой / в ячейке иконки
   (`class="err"`), не `alert`.

**Правки в других сервисах:** wallet-api — `/api/admin/icons*` (его change
`server-managed-icons`). wallet-report, google-auth, wallet-gateway — нет.

## Risks / Trade-offs

- [Веб выкатили раньше wallet-api] → «Добавить» получит `404`, покажется
  «Не удалось: …»; просмотр работает. Выкатывать после wallet-api.
- [Прозрачный PNG/SVG теряет прозрачность или масштабируется плохо] → WEBP
  и PNG прозрачность сохраняют; SVG рисуется через `Image` в canvas
  нормально. Анимированные GIF превращаются в первый кадр — допустимо.
- [Большие фото с телефона (10+ МБ)] → декодируются в браузере, наружу уходит
  только 256×256.
