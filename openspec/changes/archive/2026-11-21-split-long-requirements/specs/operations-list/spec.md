# Spec Delta

## MODIFIED Requirements

### Requirement: Карточка выбранной операции
Клик по строке SHALL выделять её и показывать в боковой панели карточку: название,
тип («Расход», «Доход», «Перевод»), сумму, «Дата» («<ДД> <месяц в родительном падеже>
<год>, ЧЧ:ММ»), «Списано с», «Зачислено на», «Сумма проводки» и «Комментарий» (если
есть).

#### Scenario: Выбор перевода
- **WHEN** пользователь кликает перевод
- **THEN** карточка показывает тип «Перевод» и пояснение «Перевод хранится двумя связанными проводками — по одной на каждый кошелёк, если валюты кошельков различались.»

#### Scenario: Повторный клик
- **WHEN** пользователь повторно кликает выбранную строку
- **THEN** выбор снимается

#### Scenario: Операция выпала из фильтра
- **WHEN** выбранная операция перестала проходить под фильтры
- **THEN** карточка не показывается

#### Scenario: Карточка без кнопок правки
- **WHEN** пользователь выбирает любую операцию
- **THEN** в карточке нет кнопок «Изменить» и «Удалить»

## ADDED Requirements

### Requirement: Пояснение о проводках в карточке
Карточка SHALL заканчиваться пояснением о проводках: у перевода — «Перевод хранится
двумя связанными проводками — по одной на каждый кошелёк, если валюты кошельков
различались.», у расхода и дохода — «Одна проводка: <откуда> → <куда>.».

#### Scenario: Выбор расхода
- **WHEN** пользователь кликает расход «Кошелёк → Такси»
- **THEN** карточка показывает пояснение «Одна проводка: Кошелёк → Такси.»

#### Scenario: Выбор дохода
- **WHEN** пользователь кликает доход «Зарплата → Кошелёк»
- **THEN** карточка показывает пояснение «Одна проводка: Зарплата → Кошелёк.»

### Requirement: Карточка не правит операции
Карточка SHALL NOT изменять и удалять существующие операции; новые операции
добавляются отдельной формой «+ Операция» (manual-operation-entry).

#### Scenario: Форма при выбранной операции
- **WHEN** пользователь выбрал операцию и нажал «+ Операция»
- **THEN** открывается форма новой операции, выбранная операция не изменяется
