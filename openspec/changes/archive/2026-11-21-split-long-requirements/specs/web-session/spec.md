# Spec Delta

## MODIFIED Requirements

### Requirement: Ссылка-приглашение откладывается до входа
Адрес `/join/<token>` (допускается завершающий `/`, токен URL-декодируется)
SHALL сохранять токен в `localStorage` до запроса
`/auth/me`, чтобы он пережил уход на Google и обратно. Недоступное хранилище
не мешает входу, но тогда приглашение после входа не примется.

#### Scenario: Незалогиненный открывает приглашение
- **WHEN** пользователь без сессии открывает `/join/abc`
- **THEN** показывается экран «Приглашение в кошелёк», а токен `abc` сохранён в браузере

#### Scenario: Приглашение и вход по паролю
- **WHEN** пользователь с открытым `/join/abc` входит по паролю на этом же экране
- **THEN** страница не перезагружается через Google, токен `abc` остаётся в браузере до приёма приглашения

## ADDED Requirements

### Requirement: Экран приглашения без сессии
Без сессии `/join/<token>` SHALL показывать экран «Приглашение в кошелёк» с текстом
«Вас пригласили в общий кошелёк. Войдите или создайте аккаунт — после входа
приглашение примется само, и вы окажетесь внутри.» и теми же способами входа,
что на экране входа.

#### Scenario: Текст приглашения
- **WHEN** пользователь без сессии открывает `/join/abc`
- **THEN** экран содержит заголовок «Приглашение в кошелёк» и текст «Вас пригласили в общий кошелёк. Войдите или создайте аккаунт — после входа приглашение примется само, и вы окажетесь внутри.»

#### Scenario: Способы входа
- **WHEN** сервер объявляет вход по паролю и через Google, и пользователь без сессии открывает `/join/abc`
- **THEN** на экране те же форма входа по паролю и вход через Google, что на экране входа
