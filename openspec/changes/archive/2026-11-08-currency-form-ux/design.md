# Design

## Context

- Экран «Курсы валют» (`renderCurList`) перерисовывает `#cur-root` целиком.
  Справочник валют — блок `#cur-currencies` внутри него, раскрывается кнопкой
  «Валюты» (`curCurrenciesOpen`). Форма валюты (`curCurrencyForm`) рисуется
  в том же блоке над таблицей. Чтобы перерисовка `#cur-root` не стирала
  набранное, есть `curCurrencyFormCapture()`.
- Иконки-флаги — `fetchReport('icons')`, `icon_type = 1`. Их имена заданы
  людьми и не единообразны: в `android-wallet/app/src/main/assets/seed.json`
  есть `Flag GEL`, `Flag Euro`, `Bosnian flag`, `Croatian flag`. Код ISO в
  имени флага есть не всегда.
- Модальных окон в приложении нет. Сегментный переключатель есть:
  `.ops-seg-group`/`.ops-seg-btn` («Список операций», «Импорт выписки»).
- Поддерживаемые браузеры — актуальные Chrome/Firefox/Safari (LAN-only MVP),
  `<dialog>` и `showModal()` есть во всех.

## Goals / Non-Goals

**Goals:** см. spec `currency-pairs`.

**Non-Goals:**
- Сервер не меняется: каталог живёт в вебе, `POST /api/currencies` получает
  те же поля, что и раньше.
- Каталог не синхронизируется с телефоном и не редактируется из интерфейса.
- Подтверждение удаления остаётся `window.confirm` — как у пар и курсов.

## Decisions

### D1. Вкладки вместо кнопки «Валюты»
`curTab` (`'pairs'` | `'currencies'`) заменяет `curCurrenciesOpen`. Шапка
списка — `.ops-seg-group` с «Валютные пары» / «Справочник валют» и главной
кнопкой вкладки справа («Добавить пару» / «Добавить валюту»). Поиск пар
виден только на вкладке пар. Переключение вкладки перерисовывает `#cur-root`
(`renderCurList`). Таблица валют по-прежнему перерисовывается отдельно
(`renderCurCurrencies`), когда справочник приходит позже.
Альтернатива — кнопка «+» с меню «Добавить пару / Добавить валюту». Её
отвергли: меню не решает, что таблица валют всё равно скрыта.

### D2. Форма — нативный `<dialog>` вне `#cur-root`
`<dialog id="cur-currency-dialog" class="cur-dialog">` лежит в `#view-cur`
рядом с `#cur-root`. `renderCurList` его не трогает, поэтому
`curCurrencyFormCapture()` больше не нужен. `showModal()` даёт затемнение,
`inert` для остальной страницы, Esc (событие `cancel`) и возврат фокуса.
Закрытие (Esc, «Отмена», клик по самому `<dialog>` вне `.cur-dialog-body`,
успешное сохранение) сбрасывает `curCurrencyForm`. `switchReportsView` при
уходе с `cur` закрывает окно: иначе модальное окно в скрытой вкладке
оставило бы страницу инертной (уход возможен через «Назад» браузера).
События окна — отдельный делегирующий слушатель на `<dialog>` в
`wireCurEvents`.

### D3. Каталог `CURRENCY_PRESETS` в `app.js`
Массив `{iso, name, symbol, precision, flag: [подсказки]}` — около 40
валют, включая `USDT`, `USDC`, `BTC`, `ETH`. Названия на русском.
`flag` — слова для поиска иконки (ISO-код, страна по-английски, как в
именах флагов из seed). Точность — минорная единица ISO 4217 (`JPY`,
`VND`, `CLP` — 0), у криптовалют — 8 (максимум формы).

Подсказки — `<datalist>` у полей «ISO-код» и «Название» (только у новой
валюты): валюты каталога, ISO которых ещё нет в `currencyDirectory`.
Нативный `datalist` работает на телефоне без своей вёрстки списка.

Применение пресета (`curApplyPreset`): точное совпадение ISO-кода (без
учёта регистра) или названия с пресетом. Заполняются только поля, которые
пусты или были заполнены прошлым пресетом (`curCurrencyForm.auto` —
множество таких полей). Набранное руками не перетирается. Поле, которое
пользователь изменил, выходит из `auto`. При правке существующей валюты
пресеты не применяются.

### D4. Подбор флага по подсказкам пресета
`curFindPresetFlag(preset, icons)` возвращает иконку-флаг или `null`. Имя
иконки и подсказка разбиваются на слова (`curFlagNameWords`: нижний
регистр, разделители — пробелы, `_`, `-`, `.`, `,`, скобки). Подсказка
совпадает, если её слова идут подряд среди слов имени. Подсказки
перебираются по порядку (ISO-код первым), для каждой — все иконки, поэтому
`Flag USD` побеждает `American flag`, даже если тот раньше в списке.
Альтернатива — подстрока без учёта регистра. Её отвергли: короткие коды
дают ложные совпадения (`ALL` в `Small`, `RUB` в `Rubble`, `EU` в
`Neutral`). Цена решения — флаг с кодом, слитым с другим словом
(`FlagGEL`), не найдётся. Тогда пользователь выберет флаг в пикере.
Флаг ставится, только если иконка не
выбрана или выбрана прошлым пресетом. Иконки грузятся асинхронно: если
пресет применён раньше, флаг подбирается по приходу иконок
(`loadCurFlagIcons`).

### D5. Поиск в пикере иконки
Над сеткой — поле «Поиск флага»: фильтр по подстроке имени без учёта
регистра. При вводе перерисовывается только сетка (`#cur-icon-grid`), поле
поиска остаётся тем же узлом и не теряет фокус. Ячейка — флаг 34×34 и
подпись (имя иконки, обрезка многоточием). Пикер раскрыт сразу, если
иконка ещё не выбрана.

### D6. Ошибки в форме
`curCurrencyForm.errors` — `{name, iso_code, icon, form}`. Поля с ошибкой
получают класс `invalid`, текст — `<p class="cur-field-error">` под полем,
`form` — `<p class="err cur-form-error">` над кнопками. Ввод в поле снимает
его ошибку. `409 duplicate` раскладывается по `field` (`iso_code`/`name`),
прочие `409` и ошибки сети — в `form` с теми же текстами, что
`currencyErrorText`. Ошибка удаления — `curCurrenciesError` над таблицей,
сбрасывается следующим действием в таблице.

### D7. Мелочи ввода
- ISO-код: `input`-обработчик переводит значение в верхний регистр с
  сохранением позиции курсора, плюс `text-transform: uppercase`.
- Точность новой валюты — `2` (значение и плейсхолдер).
- Плейсхолдер «Символа» — текущий ISO-код, обновляется при вводе.
- Превью флага — слева в поле «ISO-код», то же, что выбрано в пикере.

## Правки в других сервисах

Не нужны: wallet-api, wallet-report, wallet-gateway, google-auth, wallet-ai
не меняются.

## Risks / Trade-offs

- `datalist` выглядит по-разному в браузерах (в Firefox — только по
  совпадению начала строки). Принимаем: подсказки — ускоритель, а не
  единственный путь, автозаполнение срабатывает и при ручном вводе кода.
- Подбор флага по имени может ошибиться на неудачно названной иконке.
  Флаг видно в превью, пользователь сменит его в пикере.
