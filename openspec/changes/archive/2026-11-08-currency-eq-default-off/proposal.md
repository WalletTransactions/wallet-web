# Proposal

## Why

Каждая новая валюта сразу получала флаг «В эквиваленте» и попадала во
все пикеры валюты эквивалента — список разрастался, флаг приходилось
снимать руками. Решение владельца (2026-11-04): новая валюта создаётся
без флага, кроме самой первой в справочнике.

Парный change — android-wallet `equivalent-picker-by-flag` (то же правило
для формы на телефоне).

## What Changes

- Форма «Добавить валюту» открывается с выключенным «В эквиваленте»;
  если справочник пуст — с включённым.
- Правка существующей валюты и значение по умолчанию в базе (`DEFAULT
  true` в wallet-api, нужен для синка старых клиентов) не меняются.

## Impact

- `site/app.js`, `openCurCurrencyForm`.
- Spec `currency-pairs`: новое требование «Флаг новой валюты по умолчанию».
